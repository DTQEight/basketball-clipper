# basketball-clipper

篮球录像进球检测与自动剪辑工具，专为**固定机位**比赛录像设计。手动标定篮筐后，自动检测进球时刻并剪辑集锦。

## 核心特性

- **固定机位免微调**：手动框选篮筐即可，无需重新训练模型
- **diff + YOLO 双确认检测**：基准帧差法高召回扫描候选进球，YOLO 软确认标记是否有球在篮筐附近，兼顾召回率与可信度
- **滚动基准帧**：每 60 秒自动更新基准帧，解决长视频光线/背景变化导致的漏检
- **独立片段预览 + 人工确认**：每个检测到的进球生成独立 480p 预览片段，Radio 点击即预览，勾选实时生效（✅/❌ 标记保留状态）
- **批量识别**：文件夹模式批量标定 + 批量检测，每个视频独立保存历史记录
- **原画质集锦输出**：集锦视频保持原视频分辨率，NVENC 硬编 cq=20 接近无损
- **GPU 全链路加速**：YOLO 推理（CUDA）+ 视频编码（NVENC 硬编）+ 转码（GPU 硬解硬编）
- **视频兼容性强**：PyAV 读取，支持 HEVC 编码和 moov atom 后置的 mp4
- **历史记录**：保存检测数据，支持加载后直接剪辑（显示全部进球 + 保留勾选状态）
- **可视化界面**：Gradio 顶部 Tab 布局（🎯 检测 / ✂️ 剪辑集锦 / 📂 历史记录），左侧功能区 + 右侧预览区，操作步数最少化

## 环境要求

- Windows / Linux
- Python 3.10+
- NVIDIA GPU（推荐 GTX 1650 4G 及以上），CUDA 环境
- FFmpeg（含 libx264 + h264_nvenc，由 `imageio-ffmpeg` 自带）

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

> 需安装 CUDA 版 PyTorch，参考 https://pytorch.org/get-started/locally/

### 2. 准备权重

将篮球检测 YOLO 权重放到 `weights/` 目录，命名为 `basketball_custom.pt`。若没有，首次运行会自动下载 `yolov8n.pt`（COCO 预训练，检测效果有限，建议自行训练）。

### 3. 启动交互式 Demo

```bash
python demo_interactive.py
# 浏览器打开 http://127.0.0.1:7871
```

### 单视频操作流程
1. 输入视频文件路径（支持超大文件，不走浏览器上传）
2. 滑动到含篮筐的帧，点击画面 2 个点框选篮筐（同时采集无球基准帧）
3. 设置起止帧、球检测置信度、最小进球间隔
4. 点击「开始检测」→ 生成每个进球的独立预览片段，自动播放第一个
5. 在「检测」Tab 右侧点 Radio 选项预览任意进球（✅=保留 ❌=未保留）
6. 勾选/取消勾选实时生效，无需额外确认按钮
7. 切到「剪辑集锦」Tab → 点击「生成集锦」→ 输出原画质集锦 mp4

### 批量识别操作流程
1. 输入文件夹路径，点击「加载」→ 自动扫描视频列表
2. 从视频列表选择视频 → 加载到预览区 → 标定篮筐 → 保存标定
3. 重复上一步直到所有视频标定完成
4. 点击「批量识别」→ 自动检测所有已标定的视频
5. 每个视频独立保存历史记录，可从历史记录加载单个视频生成集锦

## 进球检测算法详解

### 整体架构：diff + YOLO 双确认

```
原视频 → PyAV 逐帧解码
          ↓
    ┌─────┴─────┐
    ↓           ↓
  diff 帧差    YOLO 检测
  (高召回)     (球位置)
    ↓           ↓
    └─────┬─────┘
          ↓
   diff 触发候选？
     ├── 是 → YOLO 软确认（检查时间窗口内球是否在篮筐附近）
     │         ├── YOLO 有球在篮筐附近 → 标记 yolo_confirmed（高可信）
     │         └── YOLO 没球或跟错    → 标记 yolo_rejected 但不否决（交给人工）
     │         ↓
     │   注册候选进球 → 生成独立预览片段
     │         ↓
     └── 否 → 继续下一帧
                    ↓
              人工逐个确认保留/删除
                    ↓
              生成集锦（原画质）
```

### 第一阶段：diff 基准帧差法（候选筛选）

标定时取一帧无球画面作为**基准帧**，之后每帧与基准帧做差分检测运动物体。

**步骤**：

1. **基准帧采集**：用户点击 2 个点标定篮筐时，当前帧自动保存为基准帧（无球的篮筐画面）
2. **灰度差分**：当前帧与基准帧转为灰度图，做 `cv2.absdiff` 绝对差分
3. **二值化**：差分图按阈值（默认 25）二值化，像素差大于阈值的区域 = 运动物体
4. **形态学去噪**：开运算去孤立噪点 + 闭运算连接相邻区域
5. **连通域分析**：`cv2.connectedComponentsWithStats` 找所有连通域
6. **斑块筛选**：
   - 面积在 `[min_blob_area, max_blob_area]` 范围内（默认 50-5000，过滤噪声和大物体）
   - 宽度不超过篮筐宽度的 1.5 倍（排除球员身体）
   - 取面积最大的有效连通域作为候选运动斑块
7. **宽松模式触发**：运动斑块中心进入篮筐框内（y 在篮筐上下沿之间，x 在篮筐范围内）即标记为候选进球

**为什么用基准帧差法？**
- 固定机位下基准帧稳定，差分信号强
- 检测的是"运动物体"本身，不依赖 YOLO 是否检测到球（不怕漏检）
- 规则明确：斑块进框 = 候选，最大化召回率

### 第二阶段：YOLO 软确认（可信度标记）

diff 触发候选后，检查 YOLO 是否在同一时间窗口内检测到球在篮筐附近。

**软确认逻辑**（非硬否决）：
- 缓存最近 10 帧（约 0.33 秒）的 YOLO 球位置到 `ball_pos_history`
- diff 触发时，检查这 10 帧内**是否有任何一帧** YOLO 检测到球在篮筐附近
- 篮筐附近定义：篮筐框外扩 100%（x 和 y 方向各外扩一个篮筐宽/高）
- YOLO 有球在篮筐附近 → `yolo_confirmed`（高可信度）
- YOLO 没球或跟错物体 → `yolo_rejected` 但**不否决**，仍注册候选

**为什么是软确认而不是硬否决？**
- 底角视角下球轨迹斜向，YOLO 常跟错物体（如球员头部）或漏检
- 硬否决会导致真实进球被漏掉（实测 YOLO 整体只有 25% 的帧检测到球，篮筐框内更少）
- 软确认保留所有 diff 候选，最终由人工确认过滤误报

**时间窗口检查（而非单帧检查）的原因**：
- 进球是一个过程（约 0.3 秒），即使触发瞬间 YOLO 漏检，前后帧检测到球也能确认
- 单帧检查的确认率仅 5%，时间窗口检查大幅提升确认率

### YOLO 篮球检测

- **模型**：自定义训练的 `basketball_custom.pt`（基于 YOLOv8n）
- **推理分辨率**：1280×1280（提升小目标检出）
- **置信度阈值**：默认 0.3（可调 0.1-0.9）
- **几何过滤**：长宽比 0.4-2.5、最小边长 ≥5px、最大边长 ≤30% 画面
- **GPU 加速**：`device="cuda:0"`

### 可调参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 球检测置信度 | 0.3 | YOLO 检测球的置信度阈值，降低可提升检出率 |
| 最小进球间隔 | 3 秒 | 两个进球间的最小时间间隔，防止重复计数 |
| 帧差阈值 | 15 | diff 二值化阈值，低=灵敏（15）/ 高=严格（35）|
| 最小斑块面积 | 30 | 过滤小噪声 |
| 最大斑块面积 | 5000 | 过滤大物体（人）|
| 搜索范围 | 80px | 篮筐周边搜索运动物体的范围 |
| 滚动基准帧间隔 | 60 秒 | 自动更新基准帧，解决长视频背景变化漏检 |

## 视频输出说明

### 预览片段（480p，GPU 硬编加速）

每个检测到的进球生成一段独立预览视频，供人工确认：
- 分辨率：480p（原 1080p 降采样，加速生成）
- 编码：H.264（优先 NVENC 硬编，回退 libx264）
- 质量：NVENC cq=26 / libx264 crf=26（中等，预览用够了）
- 时长：进球前后各 3 秒
- 生成方式：ffmpeg 直接切片 + 转码（单次完成，非逐帧处理）

### 集锦视频（原画质，GPU 硬编）

确认保留的进球拼接成集锦：
- 分辨率：保持原视频（不缩放）
- 编码：H.264（优先 NVENC 硬编，回退 libx264）
- 质量：NVENC cq=20 / libx264 crf=18（接近无损）
- 音频：AAC 128k
- 合并逻辑：相邻片段间隔小于 `min_gap`（默认 8 秒）则自动合并

## YOLO 训练流程

### 1. 手动标注（推荐，质量高）

```bash
# 追加标注 200 帧
python label_tool.py --video "video.mp4" --frames 200

# 指定时间范围抽帧
python label_tool.py --video "video.mp4" --frames 100 --start 1000 --end 2000

# 用现有模型预标注辅助
python label_tool.py --video "video.mp4" --frames 100 --prelabel
```

快捷键：`n` 下一帧 / `p` 上一帧 / `s` 跳过 / `u` 撤销 / `a` 预标注 / `d` 删除 / `w` 保存 / `q` 保存退出

### 2. 自动训练（伪标注，快速但需人工清洗）

```bash
python auto_train.py --video "video.mp4" --frames 300 --epochs 50
```

自动抽帧 → 颜色 + 形状约束伪标注 → 训练 → 输出 `weights/basketball_custom.pt`

### 3. 训练建议

- 推理分辨率 `imgsz=1280`，提升小目标检出
- 置信度阈值 `0.3-0.4` 平衡检出率与误报
- 加入硬负样本（橙色非球物体）减少误检
- 数据增强：HSV 色调、旋转、缩放、Mosaic、Mixup

## 常见问题

**Q: 上传大视频中断？**
A: `demo_interactive.py` 改用文件路径输入（不走浏览器上传），支持任意大小视频。缓存目录已设到 `E:\bball_cache`，避免 C 盘空间不足。

**Q: 视频显示 "video not playable"？**
A: 非 H.264 编码（如 HEVC）浏览器不支持。用 `transcoder.py` 转码到 H.264。

**Q: Gradio 报 `ERR_ABORTED` 访问失败？**
A: 浏览器缓存旧会话导致 SSE 连接失效。关闭旧标签页，用无痕窗口（Ctrl+Shift+N）或硬刷新（Ctrl+Shift+R）访问。

**Q: YOLO 检测不到球 / 误检橙色腿为球？**
A: ① 用 `label_tool.py` 手动标注高质量数据重训；② 降低置信度阈值；③ YOLO 检测已加几何过滤（长宽比 0.4-2.5、面积范围），可进一步收紧。

**Q: 进球漏检多？**
A: 降低帧差阈值（如 15）、减小最小斑块面积（如 30）、扩大搜索范围（如 80）。查看诊断信息中「运动斑块检测率」，低于 50% 说明参数太严格。

**Q: 进球误报多？**
A: 误报由人工确认环节过滤。每个进球都有独立预览片段，勾选保留真实的进球即可。也可提高帧差阈值（如 35）从源头减少候选。

**Q: YOLO 软确认的确认率很低（如 5%）正常吗？**
A: 底角视角下 YOLO 常跟错物体或漏检，确认率低是正常的。软确认不否决候选，最终由人工确认过滤，不影响召回率。
